Запуск на хостинге (Bothost и похожие)
=====================================

Файлы для хостинга уже в архиве: Dockerfile, Procfile, runtime.txt.

1. Создай бота в панели: платформа Discord, язык Python.
2. Загрузи код: либо этот архив (если есть загрузка файлов), либо через Git —
   создай приватный репозиторий на GitHub, залей туда содержимое папки
   (БЕЗ файла .env!) и подключи его.
3. Команда запуска, если спросят:  python bot.py
   Файл зависимостей:              requirements.txt
4. Переменные окружения:
   DISCORD_TOKEN = токен бота
   DATA_DIR      = путь к постоянному диску, если хостинг его выдаёт
                   (например /data или /app/data). Без него база будет
                   в папке проекта и может стереться при пересборке.
5. Запусти. В логах должно появиться «Вошёл как Network's Bot».

Файл .env на хостинг НЕ загружай — токен задаётся переменной окружения.
